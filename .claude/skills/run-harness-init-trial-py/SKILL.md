# harness-init-trial-py の起動・確認・停止

パスはすべてリポジトリの根からの相対である。

## 前提

- 道具は Python 3.9 以上だけである。依存は無く、入れる手順も無い（標準ライブラリだけを使う）。
- このアプリは、実行すると結果を出して終了するコマンドである。待ち受けを続けるサーバーではないので、ホストとポートは無い。

## 起動のコマンド

リポジトリの根で、インストールせずに実行する。

```sh
# ファイルを読む（-n は出す語の数。省略すると 10）
PYTHONPATH=src python3 -m wordtally README.md -n 5

# 標準入力を読む
echo "b a b c b a" | PYTHONPATH=src python3 -m wordtally -n 2
```

## 起動の完了の確かめ方

コマンドが終わったことと、終了コード・標準出力で確かめる。

- 終了コードが 0 である。
- 標準出力の各行が「回数、タブ、語」で、回数の多い順（同じ回数なら語の昇順）に並ぶ。
  `echo "b a b c b a" | PYTHONPATH=src python3 -m wordtally -n 2` の出力は `3<タブ>b` と `2<タブ>a` の 2 行になる。
- `-n` に 1 未満を渡すと、標準エラーに `--limit must be 1 or more` を出して終了コード 2 で終わる。
  存在しないファイルを渡すと、例外を出して終了コード 1 で終わる。

## 止め方と止まったことの確かめ方

実行すると自分で終了するので、止める操作は要らない。終了コードを読んで、終わったことを確かめる。

## 確認用のデータで起動する方法

外部へ通信しないので、入力を固定すればよい。標準入力に文字列を渡す
（`echo "b a b c b a" | PYTHONPATH=src python3 -m wordtally -n 2`）か、リポジトリにあるファイル（`README.md` など）を渡す。
